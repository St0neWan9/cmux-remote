FAQ

Before you begin,
a few answers.

Which agents and actions are supported?+

Structured conversations focus on Claude Code and Codex. Send prompts, read history and tool records, inspect files and diffs, stop tasks, and answer supported questions and permissions. Approved devices can also start conversations or resume eligible ones.

Does the Mac need to stay running and awake?+

Yes. Agents run on the Mac, and Cmux and Cmux Remote must remain available. If the Mac sleeps, shuts down, or goes offline, the phone cannot read live updates or control tasks.

Do I need a relay when I am away?+

Not always. Connect directly when an existing VPN, Tailscale, or another reachable network provides access to the Mac. Otherwise, deploy your own Cloudflare relay. This project does not provide a hosted relay service.

How do I grant or revoke access?+

Request pairing from the phone, then approve that device and select its workspaces on the Mac. Revoke each device individually; changes to its access scope require approval on the Mac.

How does saved history differ from live status?+

Conversation pages you have read are saved on the phone so you can see them when reopening. Live updates and actions still require a connection to the Mac. Saved history does not establish a task’s current state.

Can I connect from another Mac?+

Use Companion workspace mirroring for approved remote terminal workspaces, or use the native Cmux cmux ssh command. Their capabilities differ from mobile structured conversations. Read the Mac connection guide
