03 / 与官方比较

选择适合你的
移动开发方式。

Cmux 官方移动客户端提供终端远程操作体验。
Cmux Remote 围绕 Claude Code 与 Codex 的会话组织界面。

比较维度Cmux 官方移动客户端Cmux Remote
主要交互官方页面主打实时终端镜像、工作区切换和完整键盘。以结构化会话、工具卡、问题卡和 Diff 为主要界面。
Agent 范围终端模式适合各种命令行 Agent 和 TUI 程序。重点支持 Claude Code 与 Codex 的结构化操作。
移动平台公开提供 iPhone / iPad 入口。提供 iOS、Android 客户端。
配对方式官方 Mac 配对流程提供账号连接等方式。无需项目账号，扫码申请并由 Mac 确认设备权限。
远程接入提供 Auto-Connect、Tailscale Only 等连接方式。可达网络直连，或使用自行部署的 Cloudflare 中转。

官方源码也包含聊天相关接口。此处比较主要交互方式与连接选择，具体能力以所用版本为准。

连接你的 Mac，
打开第一个任务。

准备一次，让手机接入现有的开发环境。

01

准备 Mac

安装并运行 Cmux 和 Cmux Remote，开启共享，选择允许访问的工作区。

02

配对手机

03

开始开发

打开已有会话，或在获准的项目目录中开始新任务。需要外网访问时，再配置网络或自建中转。

常见问题

开始之前，
你可能想知道。

支持哪些 Agent 和操作？+

结构化会话重点支持 Claude Code 和 Codex。可以发送要求、查看历史与工具记录、阅读文件和 Diff、停止任务，以及回应支持的问题与授权请求。获准设备还可新建会话或恢复符合条件的会话。

Mac 是否需要保持运行和唤醒？+

需要。Agent 在 Mac 上运行，Cmux 与 Cmux Remote 需要保持可用；Mac 休眠、关机或离线时，手机无法继续读取实时状态或操作任务。

在外网使用，必须部署中转吗？+

不一定。已有 VPN 或 Tailscale 等网络能访问 Mac 时，可以直连。无法直达时，再配置自己的 Cloudflare 中转。本项目不提供托管中转。

如何授权或撤销手机访问？+

手机发起配对后，在 Mac 上批准该设备并选择可访问的工作区。每台设备可单独撤销，新的授权范围需要由 Mac 确认。

手机上的历史与实时状态有什么区别？+

已读取的对话会保存在手机上，重新打开时可以先阅读这些内容。实时进展和操作仍需要连接 Mac；已保存的历史不代表任务当前的运行状态。

能否从另一台 Mac 接入？+

可以使用 Companion 的工作区镜像接入已授权的远端终端工作区；也可以使用 Cmux 原生的 cmux ssh。两者的能力与手机结构化会话不同。查看 Mac 连接指南
