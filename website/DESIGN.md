# Cmux Remote 网站适配

版本 0.4 · Warm Neutral / Blue Accent / Bento Quiet。共同产品规范见 [根目录 DESIGN.md](../DESIGN.md)，数值源见 [design/tokens.json](../design/tokens.json)。

- 消费生成的 `tokens.css`；主按钮、链接、当前选择、功能图标和焦点使用蓝色。页面恢复暖白，所有同级外层卡片共用原来的暖灰表面与中性描边。
- 品牌大小写不受标签的 uppercase 样式影响；iPhone、Mac 始终保留标准写法。
- 场景与设备图示使用 Mac / iPhone；客户端平台与兼容性使用 macOS / iOS。下载入口保留“下载 Cmux Remote Mac”“安装 Cmux Remote iOS”。
- 根目录页面为英文，`zh/` 为中文，使用共享 CSS 与脚本。Header 右侧按「纯地球图标语言菜单 / GitHub / 开始使用」排列，两个图标共用 `.header-icon-button` 的 44px 点击区域、默认颜色、胶囊形 hover 背景与焦点样式；地球 SVG 使用 22px、GitHub 使用 24px 画布，以校准轮廓图标与实心图标的视觉大小。语言菜单显示 English / 简体中文并标记当前语言，支持点击外部或 Escape 收起，切换保留当前锚点。窄屏在 Header 内换行，顺序不变，记住主动选择；保持 English 默认，不按浏览器语言自动切换。两版保留相同的信息顺序、语义色与真实设备比例，按文本长度调整换行。
- GitHub 图标链接固定在头部“开始使用”按钮左侧，桌面与手机均显示；触控区域至少 44 × 44，提供可访问名称、悬停提示与键盘焦点。开源模块保留文字入口。
- 页脚以 GitHub 的可见轮廓为参照：GitHub 24px 画布、X 16px、Discord / Telegram / Reddit 20px，原始比例不变，统一 44 × 44 点击区域和居中。所有图标均为链接，共用同一蓝色文字 / 暖灰背景 hover 与焦点样式。未提供目的地址的四个社媒使用 `href="#"` 空链接并标注“链接待补充”；点击不会跳转或滚动，收到真实地址后去掉占位标记。
- 字号使用共享令牌：正文 16px、首屏介绍 18px、按钮 14px / 21px 行高、导航 15px、辅助说明 14px、标签与元数据 12px。窄屏通过换行与单列排版保持可读字号，设备屏幕示意维持真实物理缩放。
- 蓝色仅作为按钮、标题强调、链接、图标、选中态和焦点的点缀，不染色大面积背景。
- 完整原稿保存在 `reference/PATTERN.md`；复用记录在 `reference/ADOPTION.md`。字体 Plus Jakarta Sans / JetBrains Mono；CTA 胶囊 999px、11px × 22px、600 字重；卡片 16px、统一 28px 内边距（窄屏 24px）；容器 1280px、页面留白 80px、区域 64px、12 列、沟槽 20px（窄屏 16px）。设备屏幕与 Git 差异保持真实或语义颜色。
- 同框电脑/手机宽度比约 4.366:1，以 MacBook Pro 14 英寸和 iPhone 16 为参照。响应式尺寸一起缩放；不单独放大手机。
- 设备中的文字仅作示意；切换控件在设备外以可读尺寸呈现。
- 当前网站实现了共享设计规范。Mac/iPhone 的规范已统一，原生界面迁移需另做实现与验收。
- 颜色、浅深色组件与平台映射预览位于 `design-system.html`。
- 这是独立静态网站，使用 Cloudflare Workers Static Assets 部署；不依赖 Codex Sites 身份、登录或托管配置。设备与会话均为 HTML 示意。
- 首页以“远端运行 Agent → Mac 的 SSH / 工作区镜像 → iPhone 会话 → 网络路径”为叙事；画面明确远端执行位置，cmux 原生 SSH 与 Companion 能力分别标注。
- 视频位置通过 `videos.json` 配置，可按页面语言（`en` / `zh`）分别指定；源为空时显示“演示待补充”的静态图示，不显示假播放按钮。视频不自动播放；支持封面、字幕与加载失败回退。演示视频使用同一套暖白底、蓝色强调与字体，加速片段需在画面中标明。
- 手机交互细节在单独的会话面板放大展示，避免破坏同框设备比例。会话、改动、授权标签支持键盘切换；静态发送与授权示意不能伪装成能操作真实 Agent 的按钮。

- Tabs 与分段选择复用 `.segmented-control`：参考页 Navigation 示例的 16px 底槽 / 8px 内项圆角、4px 底槽内边距、8px × 16px 标签内边距、14px 文字；选中项中性浅底 / 主文字 / 600，无外框、无主按钮蓝填充。标签可见高度 37px、底槽 45px；透明点击扩展至 44px；窄屏减少横向内边距，必要时横向滚动而不缩小字号。

- 中文页面的标题、营销标签、演示占位、状态与无障碍说明使用中文；仅保留产品名、标准技术名、语言自称、许可证标识、命令与示例路径等固定内容。不能把装饰性的英文眉题当成品牌名保留。中文页面引用原生 UI 的固定分组名时加引号（如“Remote”）。

- 英文设备分区标签固定写作 `On Your Mac`、`On Your iPhone`；整条标签保留大小写，不出现 `ON YOUR Mac` 这种混合形式。`Tailscale` 同样保持品牌原有大小写。

- 首屏距 Header 分割线的上内边距单独使用 `layout.intro-top = 32px`，其余区域间距仍为 64px。

- 首屏在桌面端使用两列两行网格：标题与说明在首行顶端对齐，下载按钮与接入链接在次行底部对齐。中英文共用布局，DOM 按标题 / 说明 / 下载 / 接入的阅读顺序排列；窄屏按相同顺序单列堆叠。
