- 标签：8px × 16px 内边距、8px 圆角、Plus Jakarta Sans 14px / 21px、默认 500 / 次文字色。
- 选中：页面表面色、主文字色、600 字重；无蓝色主按钮填充。

- `.segmented-control` 为共享实现；首页 Chat / Changes / Permissions、设计预览主题和权限分段共用样式。英文、中文同步。

## 按钮与 Tab 高度校准

再次读取参考页实际样式：Header CTA 为 14px / 21px + 上下 11px = 43px；Tabs 标签为 14px / 21px + 上下 8px = 37px，底槽上下各 4px，总高 45px。本站显式设置控件行高，不继承正文 1.7；移除会撑高可见背景的 min-height。次按钮用内描边，不额外增加高度；系统预览共用同一数值。正文 16px / 首屏 18px 保持不变。
