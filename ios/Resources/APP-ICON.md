# Cmux Remote app icon

The active iOS icon is `Assets.xcassets/AppIcon.appiconset/AppIcon-v3.png`.
It was generated with the built-in image generation tool, then normalized from
1254 × 1254 to 1024 × 1024 pixels with `sips`. It is opaque RGB. The system adds
its own icon mask; the artwork fills the square canvas.

The phone display name is **Cmux Remote** in English and Simplified Chinese.
The App Store Connect record is **Cmux Remote Companion**, Apple ID `6821932840`.

## Generation prompt

Use case: logo-brand. Create an original finished iOS app icon for a small independent app named Cmux Remote that connects a phone to an existing remote coding workspace. Asset: square 1024 by 1024 pixel App Store app icon. Full-bleed rich cobalt blue background with a very subtle smooth blue gradient; no outer frame, no rounded-square mask, no transparency. A single bold, beautifully balanced pure white connection emblem centered with generous margins: two linked rounded rectangles, one wider desktop/workspace shape and one smaller upright phone shape, joined into a unified geometric symbol. Integrate a small elegant command-prompt chevron in the desktop shape as a secondary detail. Flat precision vector-like design, optical balance, thick consistent shapes, crisp edges, refined contemporary Apple-platform developer-tool identity, readable at 32 pixels. No app-name text, no letters, no tiny details, no photographic phone, no 3D rendering, no glossy effects, no existing brand marks, no watermark. Produce the icon artwork itself filling the square canvas, not a device mockup or a presentation.
