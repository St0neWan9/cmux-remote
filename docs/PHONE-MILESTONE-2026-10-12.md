# M1：现有 cmux 会话的 iOS 对话预览版

日期：2026-10-12。代码位于 `codex/phone-completion`，发布在
[草稿 PR #2](https://github.com/St0neWan9/cmux-remote/pull/2)。这次按要求收敛到
一个可回顾的阶段版本；完整 R01–R11 目标仍未完成。

## 这个版本能做什么

- 独立局域网设备配对，保留二维码、主机身份/证书校验和 Mac 主人批准。
- 只浏览有 cmux 绑定的现有 Claude/Codex 会话，阅读已有记录、工具详情和最佳努力实时预览；手机不实现 terminal。
- 白色对话/辅助页面、悬浮输入与控件、左侧抽屉、运行时间和回复操作。
- 通过现有 cmux 会话发送文字/受限图片；发送结果未知时保留 UUID 与草稿，查回执或明确检查后处理。
- 完整工具文本分页；历史图片通过会话引用打开白底预览，包含复制/分享控件。
- 设备端语音识别准备文字草稿，确认后追加到原草稿。录音不上传、不自动发送；不支持智能体实时语音通话。

当前前台刷新仍承担对话更新；服务端推送尚未落地。缺少记录字节的外部历史图片、
特殊媒体格式不会被当作可预览图片；不会任意导出 Mac 文件。

## 已有证据

- 104 项 Swift 包测试（23 个 suite）、87 项实际手机模型检查通过。
- iOS 模拟器构建通过；211 项英中本地化键一致，4 项权限说明在构建产物及两个语言资源中确认。
- 读取生命周期、历史图片和语音分别完成独立审查；已复现的读取竞态、分页饥饿、图片权限和归属问题均已修复，并记录红/绿结果。
- 现有官方 cmux 已向同一测试 Claude 会话投递图片，实际 Read 返回图片并识别为蓝色。
- 原配对客户端通过更新的 Bridge 读到真实工具文本及 32×32 蓝色图片（795 字节 JPEG），证书与设备授权保持不变。
- 原模拟器完成抽屉基本交互、Read 路径显示、历史图片预览。只保留这一台任务自己的模拟器；其他任务的设备未被操作。

## 距离完整目标还有什么

| 工作包 | 当前状态 | 完成门槛 |
| --- | --- | --- |
| 实时推送（R03） | 最大代码缺口，手机仍使用前台快照刷新 | 授权流、独立游标、断档/慢客户端、重连、撤销和两个客户端测试，以及实际增长回复 |
| 恢复收尾（R02/R04） | 读取竞态已修复；发送回执恢复已做，停止/Feed 的手机恢复交互尚未补齐 | 所有写操作未知结果不误重发，导航/后台/重启/换地址的真实交互验收 |
| 手机媒体与辅助页面（R01/R05/R06） | 选择/压缩/预览/提交与工具/文件/Feed 页面已有代码和检查，原生验收未全走完 | 真实照片/文件选择并发送、完整工具分页、复制/系统分享、异常/空/撤销态；抽屉边缘滑动及辅助功能 |
| 真机（R07/R09/R10） | 尚无真机验收证据 | 麦克风识别、摄像头扫码批准/拒绝/取消、Keychain 重启恢复、实际 Wi-Fi 断线和 LAN 换地址 |
| 整合与交付（R11） | 独立分支和 PR 可回顾；主目录还有另一任务未提交的 Mac 镜像代码 | 保留双方改动的整合候选，再执行对应检查与联调；不覆盖另一任务工作 |

普通未发送草稿跨进程持久化、全部附件来源/格式、每一种终端策略批准不能据当前证据宣称完成。
模拟器通过也不能替代真机的麦克风、摄像头、Keychain 和 Wi-Fi。

## 下一步建议

先回顾并确认 M1 的产品体验与范围；随后完成实时推送及恢复交互，再做一次集中
真机验收与主目录整合。这比现在继续扩散界面改动更容易判断离完整目标的距离。
