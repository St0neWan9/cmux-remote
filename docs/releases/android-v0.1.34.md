# TermRemote Android 0.1.34

Added Antigravity (`agy`) agent conversation support.

## Antigravity

- Antigravity (`agy`) can now be selected when starting a new agent conversation on a connected Mac.
- Live and archived Antigravity conversations appear in the conversation list and detail view alongside Claude and Codex.

## Install

Download `TermRemote-Android-0.1.34.apk`, open it on Android 10 or later. Same signing key as `0.1.33`; installs as an update.

TermRemote is not an official cmux product.
