# CmuxRemote 0.1.7

The Mac companion now lists workspaces from every open cmux window, and two
pairing-page details are fixed.

## Mac companion

- **Workspaces from every open window.** cmux scopes `workspace.list` to its key
  window, so the phone and the owner's approval page only saw one window's
  workspaces. Calls that name no window now read `window.list` and merge each
  window's own listing in order, skipping a window whose read fails. Paired
  devices can now see and filter across all open cmux windows.
- **Pairing QR code alignment.** The code on the pair-with-this-Mac page is
  centred in its card again.
- **Workspace rows toggle.** Tapping a workspace row on the pairing page can
  expand and collapse it instead of only selecting it.

## Android

The latest Android build remains
[CmuxRemote Android 0.1.21](https://github.com/St0neWan9/cmux-remote/releases/tag/android-v0.1.21);
this release changes the Mac side only.

## Install

Download `CmuxRemote-0.1.7.dmg`, open it and drag CmuxRemote to Applications.
The app is Developer ID signed and notarized for macOS 14 or later. This build
is universal (Apple silicon and Intel).

CmuxRemote is not an official cmux product.
