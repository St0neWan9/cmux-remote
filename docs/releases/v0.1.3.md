# CmuxRemote 0.1.3

Switch an agent's model from your iPhone, answer Claude's questions from the
conversation card, and a steadier Mac companion. Install it on every Mac you
share; the iPhone features below need this version on the Mac.

## New: switch an agent's model from the phone

- The conversation header shows the model the agent last reported and opens the
  agent's own choices: Claude's aliases and configured model options, or the
  models Codex lists in its picker. A typed model name is accepted too.
- The Mac switches with the agent's own command, exactly as if you typed it, and
  checks the screen at every step. A picker that does not look as expected is
  closed before anything applies, and an agent that is mid-turn is refused.
- When Claude asks to confirm a model switch, the phone asks you and sends the
  confirmation only after you agree.

## Conversations

- A question Claude asks in a cmux-tui terminal can now be answered from its
  conversation card, including multi-question and multi-choice forms.
- Reopening a conversation reuses the terminal it already has instead of
  opening a duplicate tab, and a conversation resumed on the desktop stays one
  conversation rather than appearing twice.
- A conversation stays live behind a numbered menu drawn over the prompt.
- Interrupted Claude turns are reported as idle, and a send is refused if the
  Bridge cannot confirm which terminal it belongs to.
- Reading conversations is faster after the first read, and a read that fails
  quickly is retried once.

## Mac companion

- **General** settings can start CmuxRemote at login, optionally showing only
  the menu bar icon.
- Text fields in the settings window accept cut, copy, paste, select all, undo
  and redo.
- After an upgrade the new Bridge replaces an older one that is still running,
  so features that need the new version no longer report "unsupported".
- Folders you share are offered to every workspace's new-conversation list.
- A Bridge write no longer fails after the connection loop shuts down, and
  retries toward a lost phone are bounded.

## Install

Download `CmuxRemote-0.1.3.dmg`, quit CmuxRemote from the menu bar, then drag
the new copy to **Applications** and replace the old one. Saved pairings,
approved devices and sharing settings are kept.

## Requirements

- macOS 14 Sonoma or later
- The official cmux app
