# CmuxRemote 0.1.1

A Bridge update for the CmuxRemote Mac menu bar app. Install it on every Mac you
share, so the iPhone app and connected Macs get the improvements below.

## Changes

- **Conversations use their cmux tab name.** Renaming a tab in cmux now renames
  the conversation on your phone right away. When a tab only shows its working
  directory, the agent's own title is used instead.
- **Background task notices no longer appear as your prompts.** Claude records
  background task notifications as user messages. They are now hidden from the
  conversation instead of being shown as something you typed.

## Install

Download `CmuxRemote-0.1.1.dmg`, quit CmuxRemote from the menu bar, then drag
the new copy to **Applications** and replace the old one. Saved pairings, approved
devices and sharing settings are kept.

## Requirements

- macOS 14 Sonoma or later
- The official cmux app
