# CmuxRemote 0.1.4

Zoom into screenshots on the phone, keep your place when you come back from a
detail page, and background agents that recover keep showing up. Install it on
every Mac you share; the iPhone features below need this version on the Mac.

This release ships from the personal Apple team **Huiyuan Jia** with new bundle
identifiers (`cmux-remote.desktop` on the Mac, `cmux-remote.mobile` on the
iPhone). It installs alongside the old app rather than replacing it: quit and
remove the previous `CmuxRemote` from Applications, then pair this copy once.

## Phone

- **Pinch to zoom an image preview.** Pinch between 1× and 6×, drag to look
  around while zoomed, double tap to fill the page and again to fit.
- **Detail pages no longer move the conversation.** Closing the preview, a tool
  detail or the timing page returns to the exact place you left, with the tool
  card you opened still open.

## Background agents

- **A background agent that recovers is visible again.** An agent that stops on
  an API error and is retried under the same task used to disappear from the
  phone while the Mac still showed it running; the conversation now reports it
  again as soon as its retry writes.

## Install

Download `CmuxRemote-0.1.4.dmg`, quit CmuxRemote from the menu bar, then drag
the new copy to **Applications**. Because the bundle identifier changed in this
release, pair the phone once more; the old copy can be removed.

## Requirements

- macOS 14 Sonoma or later
- The official cmux app
