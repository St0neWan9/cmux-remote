# TermRemote 0.1.11

Sharing starts on a Mac that ran CmuxRemote before.

## Sharing

- Quitting CmuxRemote left its background Bridge running on the sharing port, so Term Remote 0.1.10 reported
  "Sharing could not start. Check whether the port is already in use."
- Term Remote now stops that old Bridge when it starts its own. Only the CmuxRemote helper for the old default
  state folder is matched; cmux and custom state folders are never touched.
- If sharing already failed for this reason, it starts again once the old Bridge is gone. Sharing you turned
  off stays off.

Delete the old CmuxRemote app after installing. If it stays in Applications, it can start at login and bring
its Bridge back.

## Install

Download `term-remote-0.1.11.dmg`, open it and drag TermRemote to Applications. The app is Developer ID signed
and notarized for macOS 14 or later. This build is universal (Apple silicon and Intel).

TermRemote is not an official cmux product.
