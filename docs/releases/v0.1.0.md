# CmuxRemote 0.1.0

The first signed and notarized download of the CmuxRemote Mac menu bar app.

CmuxRemote is an independent companion for the official cmux app. It shares this
Mac's cmux workspaces with the CmuxRemote iPhone app and with other Macs on your
local network. cmux keeps owning your agents and terminals; CmuxRemote does not
connect to Claude, Codex or any provider API.

## Highlights

- **Share This Mac**: turn sharing on, choose which workspaces to offer, and pair
  a device with a five-minute QR code. Every device is approved individually and
  can be revoked at any time.
- **Connect to a Mac**: discover nearby Macs, verify the host, and mirror its
  workspaces into cmux's native Remote sidebar group.
- **Built-in service**: the `cmux-remote` command-line service is bundled inside
  the app, so no source checkout or PATH setup is needed.
- **Universal build** for Apple silicon and Intel Macs.

## Install

1. Download `CmuxRemote-0.1.0.dmg`, open it and drag **CmuxRemote** to
   **Applications**.
2. Open CmuxRemote. It lives in the menu bar and has no Dock icon.
3. Choose **Remote Settings…**. On first use, copy the setup command into a new
   cmux terminal and run it once, then click **Retry Connection**. cmux's default
   socket mode only accepts processes started inside cmux; CmuxRemote never
   changes that setting.

If you ran a development build from `~/Applications/CmuxRemote.app`, quit it and
delete that copy first. macOS asks again for Local Network access because the
app is now signed with a different identity. Saved pairings and approved devices
are kept.

## Requirements

- macOS 14 Sonoma or later
- The official cmux app
