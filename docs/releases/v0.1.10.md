# TermRemote 0.1.10

The Mac companion is now Term Remote: one remote for terminals and Agent conversations, from cmux and from Rex.

## Term Remote identity

- The app, its Bridge and the phone apps now use Term Remote names throughout: the bundle ID
  `dev.trenta.termremote.desktop`, the `term-remote://` pairing links, the Bonjour service, the signed
  connection protocol and the relay headers.
- On first launch the Bridge copies its state from `~/.local/state/cmux-remote` to
  `~/.local/state/term-remote`. The host identity and relay registration carry over; the old folder is left in
  place.
- Device grants were signed under the old protocol, so they do not carry over. Pair each phone again from
  **Add Device**, using iPhone TestFlight 1.3.0 (59) or Android 0.1.33. Older phone builds cannot connect to
  this Bridge.

## Rex

- Rex sessions appear as spaces next to cmux workspaces, and Add Device can grant them.
- A Rex conversation is titled by its pane: the block label, then the terminal title, then the folder.
- Terminals with no Agent are hidden from the conversation list.
- The Bridge starts with Rex alone when cmux is not running.

## Sharing

- The Mac calls every shared entry a space and labels each row with its source.
- Closed or detached cmux-tui workspaces no longer appear in pairing.
- Clicking the pairing QR code opens a large copy that Android cameras read reliably, and the pairing link
  can be copied.

## Terminals

- Live terminal output reaches the phone sooner: a changing screen is polled every 250 ms, a quiet one once a
  second.

## Install

Download `term-remote-0.1.10.dmg`, open it and drag TermRemote to Applications. The app is Developer ID signed
and notarized for macOS 14 or later. This build is universal (Apple silicon and Intel).

TermRemote is not an official cmux product.
