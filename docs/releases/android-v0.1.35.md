# TermRemote Android 0.1.35

Synced queued prompts, cleaner Antigravity transcripts, and updated device naming.

## Queued Messages & Antigravity

- Sending while a turn is already running now shows prompts in a synced queued-messages bar above the composer across all connected devices, instead of leaving a stuck "waiting for agent" bubble in the timeline.
- Active running status stays visible across devices while prompts are queued or Antigravity is still working.
- Fixed same-sequence transcript merging so cached messages keep the Bridge's order.
- New Android enrollments now report the device name as `Term Remote Android`.

## Install

Download `TermRemote-Android-0.1.35.apk`, open it on Android 10 or later. Same signing key as `0.1.34`; installs as an update.

TermRemote is not an official cmux product.
