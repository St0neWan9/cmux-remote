# TermRemote Android 0.1.32

Live terminal output now reaches the phone sooner.

## Terminals

- The terminal view used to replace its whole screen once a second, so
  output that was already on the Mac lagged behind on the phone.
- While the screen is changing it now polls again after 250 ms; a quiet
  screen falls back to the one-second cadence.

## Install

Download `TermRemote-Android-0.1.32.apk`, open it on Android 10 or later. Same
signing key; installs as an update.

TermRemote is not an official cmux product.
