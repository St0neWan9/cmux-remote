# CmuxRemote Android 0.1.21

The session list no longer shows the cached-at timestamp above the Mac pills.

## Conversation list

- The `缓存于 hh:mm` line is gone. The Mac pills and the list already show the
  live state once the first read answers, and a cached timestamp on top only
  added noise.

## Verification

- 117 JVM tests, 15 Compose tests and `scripts/verify.sh` (527 Swift tests).

## Install

Download `CmuxRemote-Android-0.1.21.apk`, open it on Android 10 or later. Same
signing key; installs as an update.

CmuxRemote is not an official cmux product.
