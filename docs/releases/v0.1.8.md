# CmuxRemote 0.1.8

The Mac companion answers the conversation list several times faster, and the
first list read after a restart no longer takes ten seconds.

## Mac companion

- **The session list no longer walks every transcript.** Each list read asks
  where the conversations without a live terminal recorded their working
  directory, and every one of those questions enumerated the whole transcript
  tree with a `stat` per file. On a Mac with sixty conversations that was over a
  second of file-system work per read, paid again on every refresh of the phone's
  list and every conversation page. A transcript is now found by name, the
  directory it recorded is read once per session, and the ambiguity, symlink and
  entry-bound rules are unchanged. Measured on loopback against a real cmux
  daemon: **1.7s → 0.40s** per list read.
- **Titles are read from the end of the record.** The conversation title was
  looked for by parsing every line of every transcript; the longest record here
  is 78 MB, which made the first list read after a Bridge restart take ten
  seconds. The title is now found from the end of the file, widening only when
  the tail holds none. Measured: **10.5s → 2.4s** for a first read.

The remaining time in a list read is the cmux daemon's own session dump, which
this release does not change.

## Install

Download `CmuxRemote-0.1.8.dmg`, open it and drag CmuxRemote to Applications.
The app is Developer ID signed and notarized for macOS 14 or later. This build
is universal (Apple silicon and Intel).

CmuxRemote is not an official cmux product.
