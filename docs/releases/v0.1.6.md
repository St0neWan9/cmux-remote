# CmuxRemote 0.1.6

Questions from the cmux terminal now reach the phone intact, and Android
devices can pair with this Mac.

## Android

- **Android is a supported client kind.** The Bridge accepts an `android`
  enrollment next to `iphone` and `mac`, and the Mac companion shows a phone
  icon for that device instead of a desktop.
- **Android 0.1.0 is attached to this release** as
  `CmuxRemote-Android-0.1.0.apk`. It is its own device: it has a separate
  Ed25519 identity, needs the owner's approval, and can be revoked on its own.
  Install it on Android 10 or later, then paste the expiring code from
  **Add Device** (or scan it). The APK is signed with the Android release key,
  not with the macOS Developer ID certificate.

## Fixed

- **A question wrapped by the terminal menu is offered as a question.** When
  the cmux menu wrapped the prompt across lines, the request used to be missed.
- **The question is shown, not the terminal line above it.** A pending
  AskUserQuestion now carries its own text, so the phone answers the question
  the agent actually asked.

## Install

Download `CmuxRemote-0.1.6.dmg`, quit CmuxRemote from the menu bar, then drag
the new copy to **Applications**. Existing phone pairings are unchanged.

For Android, download `CmuxRemote-Android-0.1.0.apk` from this release and open
it on the device.

## Requirements

- macOS 14 Sonoma or later
- The official cmux app
- Android 10 or later for the Android client

## Verification

The Mac app and disk image are signed with Developer ID (Huiyuan Jia, team
7G42499LWB) and notarized by Apple. Compare downloads against
`SHA256SUMS.txt`. The Android APK is signed by the Android release key; its
SHA-256 is printed next to the asset.

CmuxRemote is not an official cmux product.
