# CmuxRemote Mac 设计系统

## 视觉基准

以本机安装的 Amphetamine 5.3.2 设置窗口为基准（General、Session Defaults、Triggers 三页的实际截图）。此规范只覆盖 Mac，移动端不在范围内。从基准中总结出的规则：

- **分类多、每页短**。内容按任务拆成工具栏分类，每页一屏能看完，不滚动。
- **窗口贴合内容**。宽度在各分类间保持不变，高度随当前分类内容变化；窗口不可由用户拉伸。
- **一个居中的表单网格**。标签列宽度等于本页最长标签，标签右对齐并带冒号；控件紧跟标签，保持原生尺寸，不横向拉满。整个网格在窗口中水平居中，所以不同分类的控件起点可以不同。
- **无卡片、无分组标题、无分隔线**。分组靠较大的垂直间距区分，背景为系统窗口背景色。
- **说明文字**为 12 点 secondary，以 `↳` 开头，紧贴在所解释的控件下方；属于复选框的说明缩进到复选框文字处。
- **列表用有边框的原生表格**：带表头、行交替底色、固定高度；操作按钮放在表格下方，作用于选中行。

## 布局令牌

`MacDesignTokens` 是数值的唯一来源；`MacPreferencePage`、`MacPreferenceRow`、`MacPreferenceNote` 是唯一的布局组件。页面里不得另加边距、卡片或自定义背景。

| 项目 | 规范 |
| --- | --- |
| 窗口 | 宽 640 点；高度为当前分类内容的拟合高度；`titled/closable/miniaturizable`，不可缩放 |
| 工具栏 | `NSToolbar`，`toolbarStyle = .preference`，`iconAndLabel`，常规尺寸；系统负责选中态 |
| 页面上下边距 | 28 点；网格水平居中 |
| 标签列 | 自动取最长标签宽度，右对齐；冒号随语言本地化（`%@:` / `%@：`） |
| 标签与控件间距 | 8 点 |
| 控件列 | 420 点；说明文字在此宽度内换行 |
| 组间距 | 24 点 |
| 组内间距 | 8 点 |
| 说明文字 | 12 点 secondary，`↳` 前缀；复选框说明缩进 20 点 |
| 文字 | 系统 13 点；标识、地址、指纹使用等宽字体并可选中复制 |
| 表格 | `Table` + `.bordered(alternatesRowBackgrounds: true)`，高 132 点；单列表格隐藏表头 |
| 行对齐 | 文本控件按首行基线对齐标签；表格、二维码按顶部对齐标签（标签下移 4 点） |
| 按钮 | 系统默认样式，`fixedSize`，不折行；表格操作按钮放在表格下方 |
| 二维码 | 黑码白底，200 点码区 + 16 点静区；不随深色模式反色 |
| 焦点 | 窗口打开时不聚焦任何输入框 |

## 分类

| 分类 | 内容 |
| --- | --- |
| 共享本机 | 本机共享（复选框）、状态与刷新、共享时的地址、端口（共享时不可改）、证书指纹 |
| 添加设备 | 允许的工作区表格（工作区 / 允许复选框）、说明、开始配对；配对中显示二维码、扫码说明、准确范围、有效期和结束配对 |
| 设备 | 待批准申请表格（设备 / 身份），选中行下方显示 workspace、权限、完整身份，以及拒绝/批准；已授权设备表格，选中行显示同样信息和撤销授权 |
| 连接远端 | 远端 Mac 下拉菜单（按“已保存的连接 / 附近的 Bridge”分组）、刷新、忘记此主机；需要时显示状态行；远程工作区表格和“镜像到本机” |
| 高级 | Bridge 数据目录与应用；日志（“显示日志…”打开单独的 Bridge 日志窗口）；cmux 连接异常时的 setup 说明、固定命令、复制和重试 |

后台服务未连接时，除“高级”外的分类都只显示 setup 说明，不展示无法操作的空控件。

Bridge 日志窗口是设置窗口之外唯一的窗口，可缩放（默认 760 × 520，最小 560 × 360，边距 16 点），尺寸同样取自 `MacDesignTokens`。顶部为级别分段控件（全部 / INFO 及以上 / 仅警告和错误）、搜索框和暂停/继续；其下一行说明显示行数并标明最新的在底部；日志区为 11 点等宽、可选中文本，WARNING 橙色、ERROR 红色、DEBUG secondary；底部为“复制全部”和“在 Finder 中显示”。菜单栏中的待批准申请直接打开“设备”。

## 行为与验收

- 批准、拒绝、撤销只作用于表格中选中的那一行；没有选择时默认选中第一行，确保操作对象始终可见。完整身份始终显示，不能只用缩写代替。撤销前使用原生确认对话框，并写明设备名称。
- 停止共享会保留身份和授权，也不会停止外连镜像。忙碌时禁用重复操作；复选框以服务返回的真实状态显示。
- 设置窗口只有一个，可复用；关闭窗口不会停止后台服务或远端 Agent。
- 中英文本地化键必须一致；工具栏标题、标签和主要按钮都必须单行显示。
- 支持系统焦点、键盘操作、文本选择和 VoiceOver。
- 必须在实际安装的 App 上检查：每个分类的窗口高度、中文和英文、长名称、空状态、二维码静区完整、批准/拒绝/撤销流程，以及关闭后重新打开窗口。截图验收标签右边界、控件左边界、基线、表格和按钮的对齐。
