# cmux Remote Mac 设计系统

## 视觉基准

采用用户提供的 Amphetamine 偏好设置截图作为本次 Mac 界面的参考：系统窗口标题、图标与文字工具栏、两列表单、原生复选框、列表、按钮。此规范只覆盖 Mac，移动端不在本次改造范围。

- 设置窗口由 AppKit NSWindow 与 NSToolbar 承载，toolbarStyle 为 preference，displayMode 为 iconAndLabel。只显示“共享本机”“连接远端”两个分类；系统负责选中态、图标与单行文字布局。
- 正文使用经典偏好设置浅灰背景（浅色为 #ECECEC，深色为灰度 0.16）。取消品牌横幅、分段切换、圆角卡片、阴影及重复页面标题。
- 常规设置采用统一两列：左侧标签右对齐、210 点宽；右侧控件左对齐；列间距 16 点。所有标签单行，说明与按钮均沿控件列对齐。
- 列表与身份核对使用系统列表和 sheet。成功状态有图标及文字，错误有明确原因，颜色不得成为唯一线索。

## 布局令牌

| 项目 | 规范 |
| --- | --- |
| 窗口 | 初始 760 × 540 点（包含工具栏）；最小 700 × 480；工具栏分类不得折行 |
| 正文宽度 | 最多 660 点，水平居中 |
| 页面边距 | 24 点 |
| 标签列 | 210 点，右对齐；标签后使用冒号 |
| 列间距 | 16 点 |
| 组间距 | 24 点 |
| 控件/说明间距 | 8 点 |
| 文字 | 系统 13 点正文；说明 11 点 + secondary；正文不使用等宽字体 |
| 元数据 | caption.monospaced；可以选择复制 |
| 按钮 | 系统 buttonStyle；动作文字固定尺寸、不得折行 |
| 列表 | 原生 bordered List；列表内按行显示，长名称尾部截断并有 help |
| 二维码 | 黑码白底，256 点码区 + 20 点静区；不随深色模式反色 |

代码中的 MacDesignTokens 与 MacSettingsRow 是对齐的唯一来源。不得在单个页面另加无依据的缩进、边距或卡片样式。MacSettingsRow 顶部对齐，标签增加 2 点基线补偿；列表和二维码不得把标签推到其后的说明文字基线上。

## 共享本机

按两列表单依次排列：

1. **本机共享**：原生复选框、真实共享状态、折叠连接详情。端口只能在共享停止时编辑，地址与完整证书指纹放在详情。
2. **待批准申请**：有申请才显示，位于二维码之前。设备名称、身份缩写、workspace 和权限范围直接可见；完整身份展开查看。批准/拒绝处理准确请求，不静默扩权。
3. **添加设备**：配对前使用有边框的 workspace 勾选列表，高度最多 104 点，可独立滚动；说明和“开始配对”沿右侧控件列对齐。默认不勾选所有 workspace。
4. **配对状态**：二维码沿控件列左边界放置，扫码说明、准确范围、有效期和结束配对放在右侧，列间距 16 点。二维码保持完整静区，不把整块居中到窗口中线。
5. **已授权设备**：原生设备列表，提供身份、范围详情与撤销授权。撤销前使用原生确认对话框，指明设备名称。
6. **刷新**：标准小尺寸按钮，放在共享状态文字旁，不插入额外品牌工具栏。

停止共享保留身份和授权，不停止外连镜像。忙碌时禁用重复操作；开关以服务返回的真实状态更新。关闭设置、刷新和切换分类不需要确认。

## 连接远端

使用一个设备列表栏（220 点）和 workspace 内容栏，保持系统设置窗口的两级信息结构。不得再嵌套 NavigationSplitView 标题或工具栏。

- 保存连接和附近设备分别标注；长名称只截断名称。
- 选中设备使用系统强调色，原生上下文菜单提供忘记连接。
- workspace 使用有边框原生列表，名称与“镜像到本机”同一行；按钮不折行。
- 镜像成功明确提示在 cmux 使用；设置窗口不呈现终端内容。
- 身份核对、等待批准、取消申请、错误恢复沿内容栏起点排列。

## 高级设置与首次连接

高级设置默认折叠，位于窗口底部；展开后数据目录输入与“应用”按钮同一行。首次缺少 cmux 连接，用同一个两列网格提供 setup 说明、固定命令、复制和重试；不得自动向任意终端输入命令或改 cmux socket 策略。

## 行为与验收

- 菜单栏显示共享状态、待批准数、设置和退出。设置复用一个窗口，关窗不停止后台服务或远端 Agent。
- 中英文本地化键一致；原生工具栏标题、设置标签和主要按钮都必须单行。
- 支持系统焦点、键盘操作、文本选择及 VoiceOver。完整身份不得被唯一缩写替代。
- 必须在实际安装版检查默认/最小窗口、中文/英文、长名称、空状态、二维码完整区域、批准/拒绝/撤销、关窗重开。
- 截图验收检查工具栏、标签右边界、控件左边界、基线、列表与按钮的对齐。编译、后端测试和实际界面验收分别记录。
